# 上流ツールとGUIの機能差分

対象: 同梱しているWindows版CLIの `--help`（2026-10-02取得）。GitHubの最新開発版との比較ではありません。

通常画面の出力解析では扱えない機能を、別ウィンドウの「詳細機能」に分けます。オプション選択・値入力・ファイル選択・標準入力・結果保存で組み立てます。シェルのパイプやリダイレクトは実行しません。

**完全な互換性や、すべての組合せの動作確認を意味しません。** 対応可能な引数を広く扱う共通画面です。各CLIの個々の機能は同梱ヘルプで確認できます。

## 共通の制限

- CLIがWindows版で実装していないOS固有の機能は追加できません。
- 外部プロセスを呼ぶripgrepのpre、fdのexec、batのpager、pastelの外部色ピッカー、fastfetchの外部設定ファイルは扱いません。
- yqは環境変数・外部ファイル読み込み・system式と直接上書きを無効にします。式で変更した結果は別ファイルへ保存できます。
- Gitleaksは検出値を100%マスクします。設定・テンプレート・診断サーバー・任意のgit log引数は扱いません。Git履歴検査にはGitの別途インストールが必要です。
- xhのセッション永続化は扱いません。認証情報を自動保存しません。
- ターミナル上の対話入力や色の再現は対象外です。標準出力は元のバイト列を保存できます。
- 1回300秒、標準入力2 MiB、出力合計16 MiB、引数256個までです。大規模ジョブはCLIを直接使ってください。
- 詳細機能にはCLIの指定先への書き込みや通信を行う操作もあります。入力・出力の場所と、送信先を指定して実行してください。

## 調査方法

オプション宣言の長短別名（例: dustの `-j` / `--json`、jqの `-M` / `--monochrome-output`、dufの単一ハイフン）を照合しました。引数文字列がコードにある個数は機能カバー率に使用していません。jqの既存の式入力は多くの演算に対応済みです。各アプリの `advanced-spec.json` と `upstream-help.txt` に同梱版の機能一覧を保存しています。

- 16本それぞれの追加操作を同梱版と同じCLIで実行し、結果を確認しました。全33プリセットも実行しました。
- 詳細画面からの実行、プリセット、画面の開き直し、終了処理を16本で確認しました。
- 通常画面の既存の機能試験を16本で実行しました。
- 16本の配布ZIPを展開し、ライセンス文書、通常画面、詳細画面、終了を確認しました。
- 共有実行処理の停止・時間制限・出力上限・バイナリ保持を試験しました。HTTPのPOSTはローカル試験サーバーへ送り、Gitleaksの検出値マスクは架空のトークンで確認しました。

個々のオプションの全組合せを試験したものではありません。通常画面に専用の操作部品を増やした機能と、詳細画面で上流の引数を組み立てて使う機能は区別してください。今回の追加は後者が中心です。
