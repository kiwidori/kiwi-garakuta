きういラベル印刷 0.1.0
Windows 11 x64 / ZIP版

名札や収納ラベルをA4用紙に並べ、PDF・PNG・SVGに保存する無料ソフトです。
Typstを利用した非公式GUIです。文字を入力するだけで使えます。
Typstの実行にはMicrosoft Visual C++ v14再頒布可能パッケージ（x64）が必要です。
未導入の場合はMicrosoft公式から手動で準備してください。
https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist

1. ZIPをすべて展開し、KiwiLabels.exeを起動します。
2. 初回のみ「エンジンを準備」を押します。Typstの公式Windows版約22 MBを取得します。
3. 一覧に1種類ずつ改行して文字を入力します。「 | 」で区切ると1枚の中で3段まで表示します。
   例：きうい | もも組 | たのしくあそぼう
4. 名札・収納用などの配置を選び、列・行・余白・間隔・文字サイズを調整します。
5. 必要なら同じラベルを複製し、「印刷前のプレビュー」で各ページを確認します。
6. PDF・PNG・SVGから選んで「別名で保存」を押します。既存ファイルは上書きしません。
7. 印刷はPDFを閲覧ソフトで開き、「実際のサイズ／100%」で行います。
   市販シール用紙を使う場合は、最初に普通紙へ印刷して位置を確認してください。

できること
・1枚に1～3段の文字を配置し、長い文字を自動で縮小します。
・列1～4・行1～12、余白5～25 mm・間隔0～10 mm、文字8～32 ptを指定できます。
・1種類あたり1～100枚の複製、枠線の有無、文字・枠の色を指定できます。
・最初は4種類のフォントを選べます。「Windowsのフォント一覧を取得」で追加のWindowsフォントも選べます。
・UTF-8のテキスト一覧を開き、複数ページをPDFまたはページごとのPNG・SVGに保存できます。
・PNGは72～200 PPI、プレビューは指定した1ページの縮小表示です。
・「出力の詳細」で保存ページを指定できます。空欄は全ページ、例：1,3-5、8-。
・PDF 1.4・1.7・2.0・PDF/A-2bと、読み取り順などのPDFタグの有無を選べます。
  ページを絞ったPDFは元エンジンの制約によりタグなしで保存します。
・元の一覧や保存済みの出力は変更しません。処理の停止にも対応します。

制限
A4縦のみ。1行120文字・1種類3行・200種類、複製後400枚・10ページまでです。
入力一覧はUTF-8（BOM可）128 KiB・200行まで。ラベルは幅25 mm・高さ15 mm以上です。
ラベル内の「 | 」は段の区切りになるので、その記号自体を印刷する用途には使えません。
日本語の表示にはWindowsの日本語フォントが必要です。フォントは同梱していません。
Yu Gothic・Meiryo・MS Gothic・Arialなどを選べます。追加一覧はWindowsのFontsフォルダーにあるものです。
利用者個別のフォントフォルダーや外部フォントは読み込みません。フォントや文字を確認できない場合は保存しません。
自動縮小により文字が小さくなる場合があります。絵文字や特殊な文字は表示できない場合があります。
市販シールの品番別テンプレート・プリンターの位置補正・自動印刷はありません。
保存するPDFからの編集、図・画像・QRの追加、自由なTypstコード・外部パッケージには対応しません。
初回準備後の作成はPC内で行い、入力した名前や文章を送信しません。
処理30秒・ファイル各20 MiB・作業領域合計64 MiBまで。リンク・ジャンクションは扱いません。
コード署名はありません。
