きうい動画保存 0.1.0
Windows 11 x64 / インストーラーなし

ZIPをすべて展開し、KiwiVideoSave.exeを起動してください。
初回のみ「エンジンを準備」を押すと、公式配布元からyt-dlp 2026.10.26を取得します。
取得サイズ：約22.5 MiB。取得ファイルのSHA-256を照合します。

上流: https://github.com/yt-dlp/yt-dlp
