きういバイト表示 0.1.1 / Windows 11 x64 インストール不要

hexyl v0.17.0の非公式GUI。ファイル1つを読み取り専用で表示するか、UTF-8テキスト/16進数列を入力できます。
読み飛ばす位置（負数は末尾から）、表示量（初期256バイト）、block単位、表示オフセットを指定します。
パネル数、枠線、基数、グループサイズとバイト順、文字表、配色、plain/C include出力を選べます。
16進数入力は「00 01 7f ff」などの空白区切りの2桁バイトです。0x接頭辞は使いません。
「デモ」でサンプルを試せます。元ファイルを変更しません。
原文は「結果を保存」、装飾なしのテキストは「プレーン保存」で保存できます。
色の凡例、ヘルプ、版表示、5種類のシェル補完生成も使えます。補完スクリプトを実行しません。
HEXYL_COLOR_NULL/OFFSET/ASCII_PRINTABLE/ASCII_WHITESPACE/ASCII_OTHER/NONASCII環境変数は起動前に設定すると上流へ継承します。専用の環境変数設定欄はありません。

入力欄2 MiB、出力合計16 MiB、300秒、引数256個/64 KiB。ファイルはCLIで直接読み取り、入力欄の容量制限とは異なります。
画面表示は先頭128 KiB・256スタイルまで。全出力は原文保存できます。色の完全な再現や全ての設定の組合せを保証しません。
端末幅とパネル数は同時指定できません。実行ファイルは未署名です。LLM・クラウドAPIは実行時不要です。
同梱Windows版は負数の表示オフセットを拒否します（ヘルプ記載と異なります）。末尾からの読み飛ばしは利用できます。
C includeとバイト順の明示指定は同時使用できません。C includeではバイト順欄を空欄にします。
