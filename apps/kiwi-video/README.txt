きうい動画工房 0.1.0
Windows 11 x64 / ZIP版

動画の形式変換・軽量化、区間の切り出し、音声だけの保存を行う無料ソフトです。
FFmpegを利用する非公式GUIです。動画エンジンは本ZIPに含まれません。

使い方
1. ZIPをすべて展開してKiwiVideo.exeを起動します。
2. 初回のみ「動画エンジンを準備」を押します。
   FFmpeg公式サイトが案内するgyan.devのGitHubから約100MBのWindows版を取得します。
   展開後は約273MBをユーザーのLocalAppData/KiwiVideoに保存します。
3. 「動画・音声を選ぶ」で最大5件を選び、「やりたいこと」を指定します。
4. 保存形式・サイズ・区間・回転・切り抜き・音声を設定します。
   「情報・プレビュー」で選択した1件の情報と、開始位置の映像を確認できます。
5. 「別名で保存」で保存先を指定します。元ファイルや既存の同名ファイルは上書きしません。

できること
・MP4（H.264 / H.265）、WebM（VP9）への変換、画質・サイズ・フレームレート指定。
・開始・終了を秒で指定した切り出し。終了0は最後まで。再圧縮するため画質は変わります。
・向きの自動補正、回転・上下左右反転、座標での切り抜き。
・MP3 / M4A / WAV / FLAC / Opusへの音声保存、音声トラック選択、消音・音量調整。
・音量のばらつきを整える処理（単一パスのラウドネス調整、目安 -16 LUFS）。
・開始位置の1コマをPNG・JPEGで保存。
・メタデータをコピーしない設定、保存結果と容量の一覧、停止、保存先を開く操作。

制限
入力：MP4・M4V・MOV・MKV・WebM・AVI・MPG/MPEG・TS・MP3・M4A・WAV・FLAC・OGG・Opus。
1件2 GiB・2時間、映像は各辺4,096px・900万画素・120fpsまで。動画・静止画の変換はSDR・8bit向けです。
HDR・10bit以上の映像変換には非対応です。音声だけの保存は利用できます。
処理は1件30分まで（プレビューは60秒）。出力1件1 GiBまで。作業用の空き領域も必要です。
コピーと出力のため入力サイズに加えて1 GiB以上の空き領域を確認します。
入力によっては処理に時間がかかるほか、音声形式・映像形式を読み込めない場合があります。
動画は再圧縮します。指定した画質でも、必ず小さくなる・特定サイズに収まる保証はありません。
H.264が互換性重視のおすすめです。H.265・VP9は再生側の対応が必要です。
最初の通常映像ストリームと、選んだ1本の音声だけを使います。字幕・チャプター・添付物は引き継ぎません。
音声は48kHz・ステレオに変換します。WAV・FLACにしても元の非可逆音声の音質は復元しません。
音量を上げると音割れする場合があります。ラウドネス調整は結果を聞いて確認してください。
プレビューはサイズ・向きの確認用で、圧縮後の画質・音の試聴ではありません。
正方画素へ調整し、奇数の縦横は偶数へ縮小します。切り抜きの座標・寸法は偶数で指定します。
無劣化の切り出し、結合、字幕焼き込み、動画再生、録画、配信、GPU処理、全CLIオプションには非対応です。
初回のエンジン取得後、動画・音声の処理で通信は行いません。画像や音声を送信しません。
リンク・ジャンクションは扱いません。途中で停止・失敗した場合も保存済みのファイルは残ります。
