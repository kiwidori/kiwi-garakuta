きうい画像拡大 0.1.1 / Windows 11 x64

小さな写真やイラストを、PC内で大きくする無料ソフトです。
ZIPを展開し、KiwiImageEnlarge.exeを起動してください。
画像を追加し、保存フォルダー・画像の種類・倍率を選んで「拡大」を押します。
一覧で画像を選ぶと、元画像と保存された画像を並べて確認できます。

必要なもの
・Vulkanの実行環境（対応GPUドライバーまたは互換描画環境）
・Microsoft Visual C++ v14 再頒布可能パッケージ (x64)
  https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist
正常に処理できるGPUや互換描画の組がないPCでは使えません。ドライバーと上記ランタイムは同梱していません。

写真 / イラスト: 4倍、軽量イラスト: 2・3・4倍。
PNG・JPEG・WebPの静止画像に対応。一度に50枚、元画像400万画素まで。
フォルダー追加は直下の画像だけを対象にします。
出力は別ファイルです。既存ファイルは上書きせず、その画像をスキップします。
途中停止した場合も、処理済みの画像は残ります。GPUの確認と拡大エンジンの実行は合わせて1枚180秒までです。
画像の向きを調整してから処理し、EXIFなどの撮影情報は保存しません。
16bit/HDR画像には対応していません。JPEG出力は透過部分が白背景になります。
拡大は推測した細部を補います。元の被写体や文字を正確に復元するものではありません。
画像を外部へ送信しません。コード署名はありません。

画像の読み取り・検証とプレビューにはPillow 13.0.0を使用しています。

WebP保存は、拡大エンジンが作るPNGをPillow 13.0.0で可逆圧縮します。
透過は保持し、撮影情報は引き継ぎません。WebP保存中の停止は、符号化の終了を待つ場合があります。

GPUの確認
画像の種類・倍率・タイル・スレッド・TTA・GPUの組ごとに、小さな既知色の画像で色と明るさを確認します。
合格した組はソフトを閉じるまで記憶します。初回は確認のため時間がかかります。
GPUをautoにすると、不合格のGPUを避け、利用できれば互換ソフトウェア描画も試します。
互換描画は遅くなる場合があります。使ったGPUと確認結果は「選択画像の記録」で確認できます。
GPUを番号で指定した場合は、確認できない組をエラーにし、別のGPUへは切り替えません。
この確認はすべての画像の品質を保証するものではありません。保存した画像を必ず見比べてください。
