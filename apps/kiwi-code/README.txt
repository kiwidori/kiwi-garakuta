きういコードビュー 0.1.0

Windows 11 x64向けの無料ツールです。ZIPを展開し、KiwiCode.exeを起動してください。
コードやテキストのファイルを選ぶと、batによる色分け表示と行番号を画面で確認できます。
開始行の指定、500行ずつの移動、テーマ変更ができます。ファイルは読み取り専用です。

対象ファイルは10 MiBまで、表示結果は2 MiBまで、処理時間は15秒までです。1回の表示は最大500行です。テキストのエンコーディングや種類によっては文字が正しく表示されないことがあります。
Windows環境によっては、batの実行にMicrosoft Visual C++ Redistributableが必要です。
