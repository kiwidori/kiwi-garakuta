きういフォルダーコピー 0.1.0
Windows 11 x64 / インストーラーなし

1. ZIPを展開し、KiwiCopy.exeを起動します。
2. 初回は「エンジンを準備」でrclone公式版を取得します。
3. コピー元とコピー先のローカルフォルダーを選び「フォルダーを比較」。
4. 追加予定・同じ内容・内容違い・コピー先だけの項目を見比べます。
5. 「不足分をコピー」で、内容を照合した新規ファイルだけ追加します。

既存ファイルの上書き・削除は行いません。名前が衝突する項目はコピーしません。空フォルダー、リンク、ジャンクション、ネットワークパス、クラウド専用ファイルは対象外です。
各フォルダー2,000件（サブフォルダー含む）・1ファイル512 MiB・合計2 GiBまで。パス長240文字まで。比較・コピーは各10分までです。
停止時は追加済みのファイルが残る場合があります。再度比較して続けられます。変更・削除の履歴は残さないため、世代管理するバックアップの代わりにはなりません。
CSVには相対パス・状態・サイズを保存します。MD5は内容の比較に使い、電子署名や真正性の保証には使いません。ACL、代替データストリーム、空フォルダー、全メタデータの複製には対応しません。
