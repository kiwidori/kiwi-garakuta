きういPC情報 0.1.0

Windows 11 x64向けの無料ツールです。ZIPを展開し、KiwiSystem.exeを起動してください。
「情報を取得」を押すと、OS・CPU・GPU・メモリ・ドライブ容量・画面解像度を一覧表示します。
「概要をコピー」で表示中の項目をクリップボードへコピーできます。

元ツールのfastfetchを使用します。表示する項目は限定しており、ユーザー名・端末名・シリアル番号・ネットワーク情報は表示しません。ファイルの変更やネットワーク通信は行いません。検出できない項目は省略します。

元ツール fastfetch: https://github.com/fastfetch-cli/fastfetch
このソフトはfastfetch開発者の公式製品ではありません。fastfetchのMITライセンスはfastfetch-LICENSEを参照してください。GUIのライセンスはLICENSEを参照してください。
