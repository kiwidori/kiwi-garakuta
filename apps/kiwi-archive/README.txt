きうい圧縮箱 0.1.0
写真や書類を圧縮し、届いた書庫の中身を確認・展開する無料ソフトです。
ouchを利用した非公式GUIです。処理はPC内で行います。
Windows 11 x64用。Microsoft Visual C++ v14再頒布可能パッケージ（x64）が必要です。
ZIPをすべて展開してKiwiArchive.exeを起動してください。nativeフォルダーも必要です。

圧縮する
1. 「圧縮する」でファイル・フォルダーを追加します。
2. 保存形式を選びます。普段の受け渡しにはZIPが便利です。
3. 「保存名を選んで圧縮する」を押し、新しい名前で保存します。
元ファイルは残り、既存ファイルは上書きしません。
同名の対象は一度に追加できません。名前を変えるか、親フォルダーごと選んでください。

中身を確認・展開する
1. 「中身を確認・展開する」で書庫を追加し、一覧から選びます。
2. 「中身を見る」で一覧を表示できます。複数選択にも対応します。
3. 展開先の親フォルダーを選び、「新しいフォルダーへ展開」を押します。
展開は1書庫ずつ。親フォルダー内に新しい「展開-…」フォルダーを作ります。
パスワード付きZIP・7z・RARは書庫パスワード欄を使います。処理後に欄を消去します。
結果はコピー・別名TXT保存できます。展開ファイルは自動で開きません。

形式・調整
ZIP、7z、tar、gzip、xz、zstd、bzip2、bzip3、LZ4、Snappy、Brotli、LZMA、lzipに対応します。
tar.gz、tar.xz、tar.zstなどの組み合わせも使えます。RARは読み取り専用です。
単独のgzipなどは1ファイル向けです。複数ファイルやフォルダーはZIP・7z・tar系を選んでください。
一覧表示は中身を持つ書庫形式（ZIP・7z・tar・RAR）向けです。
圧縮形式は選択した値が優先されます。保存名の拡張子も同じ形式にしてください。
形式欄には組み合わせを4段まで入力でき、tgz・tbz2・cbzなどの別名も使えます。
「形式指定」は拡張子と内容が異なる書庫で使います。通常は空欄にします。
autoは標準、fastは速度優先、slowは容量優先、levelは数値指定です。
レベルの有効範囲は形式ごとに異なり、合わない値では処理できません。
スレッド数は1～16。隠しファイル除外と.gitignoreは元ツールの仕様に従います。

制限
1回32対象、合計2 GiB・10,000項目、1処理5分までです。展開はサイズ・項目数を監視し、上限で中止します。
監視には短い間隔があるため、展開中に一時的に上限を超えることがあります。十分な空き容量を用意してください。
一覧・処理ログは各4 MiBまでです。大きな書庫は分けてください。
失敗・停止した展開結果は保存せず、一時フォルダーを片付けます。
リンク・ジャンクションを含む対象や展開結果、ZIP・tar内のリンクは扱いません。
ZIP・tarの重複名、Windowsで扱えない名前や保存先を外れるパスを含む書庫は展開できません。
形式によっては元ツールが扱えない圧縮方式・暗号化方式があり、一覧や展開に失敗することがあります。
パスワード付き書庫の作成、元ファイルの削除、既存フォルダーへの直接展開、任意オプション入力はありません。
隠しファイルなどの除外設定で、圧縮に含まれない項目ができます。
コード署名はありません。
