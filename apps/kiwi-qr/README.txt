きういQR 0.1.0
URLやメモのQRを作り、画像のQR・バーコードを読み取る無料ソフトです。
Windows 11 x64向け。ZIPを展開しKiwiQR.exeを起動してください。
Microsoft Visual C++ v14 再頒布可能パッケージ（x64）が必要です。
Microsoft公式の案内：https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist

QRを作る
1. URLや文章を入力します。「Wi-Fi」「連絡先」「メール」の入力画面も使えます。
2. 必要に応じて形・色・誤り訂正を変更します。中央の画像はPNG/JPEG、誤り訂正Hのときだけ使えます。
3. 「作成して確認」（F5）を押します。作成した画像を読み戻し、内容が一致したものを表示します。
4. 「PNGを保存」で保存先を選びます。白黒・四角形・画像なしのQRはSVGでも保存できます。
画像を入れたり色や形を変えたQRはPNGのみです。SVGは詳細設定でpath・rect・fragmentを選べます。
「種類」を変えるとCode128、JAN/EAN、DataMatrix、Aztec、PDF417などのバーコードも作成できます。
種類によって使える文字や桁数が違います。JAN/EANなどで検査数字が補われた場合は、作成結果に内容を表示します。
入力や設定を変更した後は、もう一度作成してください。

画像から読み取る
「画像から読み取る」で画像を追加し、「読み取る」を押します。1枚に複数のコードがあっても読み取れます。
結果を選ぶと内容を表示します。明示的なコピー、TXT/JSON保存、QR作成欄への移送ができます。
URLを自動では開きません。QRにはWi-Fiのパスワードや連絡先なども含まれうるので、共有する内容を確認してください。
既存のファイルを上書きせず、新しい名前で保存します。JSONには読み取ったバイト列（Base64）と位置も含みます。

まとめて作る
「QRをまとめて作る」へ1行に1件のURL・文章を入力し、保存先の親フォルダーを選びます。
新しいフォルダーへ001.png等を保存します。対応するQRではSVGも保存します。作成タブのQR設定が使われます。
失敗や停止では「作成中-...」フォルダーに作成済みファイルを残し、途中までの件数と場所を表示します。
詳細設定はJSONで指定でき、今回の起動中だけ保持します。版・余白・最適化・マスク、読み取りの向き・反転・形式・文字表示などを調整できます。

制限
処理はPC内で行います。カメラ、Webからの画像取得、クリップボードの自動読み取り、URLの自動起動には対応していません。
画像は1件25 MiB・2,000万画素、1回32件まで。PNG/JPEG/GIF/BMP/WebP/TIFFの最初のフレームを読みます。
処理は1回30秒、一括QRは100件・合計5分までです。結果16 MiB、PNG4 MiB、1画像の読み取り100コードまでです。
QRの入力はUTF-8で3,000バイト以内ですが、誤り訂正や版によって入る量は少なくなります。出力は一辺2,048pxまでです。
中央の画像は2 MiB・100万画素以内、QR全体の幅の15％です。読み戻せない装飾は作成を完了しません。
バーコード画像は400万画素・一辺8,192pxまでです。余白・文字の分も含む事前の制限があります。
画像を線の色として使う装飾、装飾付きSVG、QRのバイナリ入力、端末用ASCII出力は未対応です。
自動確認は実機での読み取りを保証しません。印刷・共有前に、使うスマートフォンでも読み取りを確認してください。
コード署名はありません。
