きうい読み取り・読み上げ 0.1.0
Windows 11 x64 / インストーラーなしZIP

画像の文字を読み取り、確認・修正した文章を読み上げ音声に変換します。
1. ZIPをすべて展開してKiwiReadingWorkbench.exeを起動します。
2. Microsoft Visual C++ v14再頒布可能パッケージ（x64）が必要です。
3. 「画像から文章を読む」でOCR画面を開き、画像を追加して読み取ります。
4. 文章を確認・修正し、「修正した全文を読み上げへ」を押します。
   300文字を超える場合は読む部分を選び、「選択した文章を読み上げへ」を使います。
   全文を勝手に切り捨てることはありません。
5. 読み上げ画面で言語・声・速さを確認します。
   初回は音声モデルのOpenRAIL-M利用条件を読み、同意してから準備します（約150 MiB）。
   OCRを使うだけなら、この音声モデルの取得や同意は必要ありません。
6. 「WAVにして別名で保存」を押します。試聴は自分で押したときだけ再生します。

文章は画像から移したあとも修正できます。画像を使わず本文を入力しても使えます。
文章を移すときは、既存の読み上げ本文があれば置き換えを確認します。
以前の音声の試聴対象は解除しますが、保存済みのWAVは削除しません。
OCRの文章欄から送るので、修正内容が反映されます。位置一覧の数値とは別です。

OCRの認識・文字位置・範囲・回転・一覧・各保存方法はocr-notices/README.txt、
読み上げの設定・入力制限・モデル条件はSPEECH-README.txtを参照してください。
各部品の説明にある旧実行ファイル名に代えて、本ZIPの実行ファイルを使ってください。
読み上げ本文は300文字、音声90秒、処理90秒までです。
日本語対応OCRと、31言語の読み上げは異なるモデルです。未対応の言語を自動補正しません。
任意の長文の分割読み上げや、全文の自動音声保存はありません。
推論はPC内で行います。OCRと音声は同時に処理しません。
OCRエンジンと認識モデルは同梱。読み上げエンジンと音声モデルは別取得です。
モデルの利用条件・出力の合成音声表示の条件は統合版でも適用されます。
署名なしの実行ファイルです。原文ライセンスと依存物通知を同梱しています。
