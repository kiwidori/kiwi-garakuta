きうい比較 0.1.0
Windows 11 x64向け・インストーラーなしの無料ZIP版

difftasticの非公式GUIです。元ツールの開発者とは関係ありません。
1. ZIPを展開し、KiwiDiff.exeを起動します。
2. 左・右のローカルファイルを選びます。
3. 必要に応じて「プレーンテキスト」を選び、「比較」を押します。
4. 結果をコピーするか、UTF-8のテキストとして保存します。
赤は左ファイルの変更前、緑は右ファイルの変更後を示します。保存・コピーは色の付かないテキストです。

対象は各2MiB以下のUTF-8・UTF-8 BOM付きテキストファイルです。
バイナリ・Shift-JISなどの文字コード・フォルダー比較・URL取得には対応しません。
構文比較は拡張子で言語を判定し、空白などの変更を無視する場合があります。
「差分なし」はバイト列が完全に同じという意味ではありません。
プレーンテキスト比較でもCRLFとLFの違い、およびUTF-8 BOMの有無は無視します。
未対応言語や大きなファイル、複雑な構文は行単位の比較に切り替わる場合があります。
処理は20秒、エンジン出力は2MiBまでです。表示は差分周辺の内容です。
保存結果は閲覧用テキストで、適用可能なパッチではありません。編集・マージ機能はありません。
入力ファイルを変更・実行・外部へ送信しません。保存先だけに書き込みます。
保存先には入力ファイルと同じファイルを指定できません。
現時点の実行ファイルにはコード署名がありません。
