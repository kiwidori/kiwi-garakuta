きういバックアップ 0.1.0
写真や書類を、履歴ごとに保存する無料ソフトです。
Windows 11 x64 / インストール不要。ZIPを展開してKiwiBackup.exeを起動してください。
restic 0.19.1を使う非公式GUIです。

はじめて使うとき
1. 空のフォルダーをバックアップ先（保管庫）に指定します。PC故障に備えるなら、別ドライブや外付け媒体を選んでください。
2. 8文字以上のパスワードを入力し「新しい保管庫を作る」を押します。
3. 保存するファイル・フォルダーを追加して「バックアップを保存」を押します。除外パターンとタグも指定できます。
4. 次回は同じ保管庫とパスワードを指定して保存します。変更前の履歴は残ります。

過去のファイルを戻す
「保存履歴を読む」で履歴を選びます。「中身を見る」でフォルダー・ファイルを選べます。
履歴全体、選んだフォルダー、1ファイルの取り出しに対応しています。
復元先の親フォルダーを選ぶと、新しい「復元-...」フォルダーを作ります。元ファイルや既存ファイルは上書きしません。
履歴全体の復元は保存元ごとの「01-保存元」等に分かれます。元のドライブの配置へ直接戻す機能ではありません。
フォルダーの復元は内容を検証します。1ファイルの取り出しは64 MiBまでで、大きいファイルはフォルダーを選んで復元してください。
UNCや相対パス由来など履歴全体の復元で扱えない保存元は、「中身を見る」からフォルダーを選んでください。
Windowsの権限・所有者などの復元には制約があります。別のPCやユーザー、特殊な権限のファイルでは復元できない場合があります。
途中で失敗・停止した場合は「復元中-...」フォルダーを残して場所を表示します。成功した復元とは区別してください。

履歴の管理
履歴内の名前検索、2件の比較、容量の集計、タグの追加・解除・置換、作成済みの別保管庫への複製に対応します。
「点検・整理」で全データの検査、古い履歴の削除予定、不要データの整理、古いロックの解除、暗号鍵の一覧を利用できます。
履歴削除は予定を確認してから実行します。予定後に履歴が増減した場合は再確認が必要です。削除・不要データの整理は取り消せません。
「詳細設定」では操作ごとにJSONで除外・圧縮・保持条件などを指定できます。設定は今回の起動中だけ有効です。

制限と注意
パスワードは保存しません。忘れると復元できません。別の安全な場所に控えてください。
バックアップ・復元は手動で開始します。自動スケジュール、クラウド接続、VSS、起動中のシステム全体の完全バックアップには対応していません。
暗号鍵・パスワードの変更、保管庫の修復・形式移行・履歴書き換え・孤立データ回収、内部オブジェクトの表示も未対応です。
保管庫はローカルまたはWindowsから通常のフォルダーとして使える保存先だけです。アクセス権のないファイルは保存できません。
一部失敗で作られた履歴は警告を表示します。停止しても保存や整理が一部完了している場合があるため、履歴を読み直してください。
1処理は最長1時間。保存元32件、履歴10,000件、一覧表示50,000項目、通常出力32 MiB、ログ4 MiB、履歴削除は1回255件までです。
大きな保管庫や読み出しの遅い媒体では上限に達する場合があります。保管庫には空き容量が必要です。
コード署名はありません。復元したファイルを自動では開きません。
