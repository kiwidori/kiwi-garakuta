きういGIF工房 0.1.0
写真やイラストを並べ、アニメーションGIFを作る無料ソフトです。
gifskiを利用した非公式GUIです。処理はPC内で行い、元ファイルは変更しません。
Windows 11 x64用。Microsoft Visual C++ v14再頒布可能パッケージ（x64）が必要です。
ZIPをすべて展開し、KiwiGIF.exeを起動してください。nativeフォルダーも必要です。

画像を並べて作る
1. 入力方法を「画像を並べる」にし、2～100枚の画像を追加します（F4）。
2. 一覧から1枚を選び、「上へ」「下へ」で順番を変えられます。「名前順」は数字を考慮して並べます。
3. FPSで速さを決め、幅・品質・繰り返しなどを調整します。初期設定でも使えます。
4. 「保存名を選んでGIFを作る」（F5）で、新しい.gifファイルへ保存します。
5. 作成結果を画面内で再生できます。保存先フォルダーを開くこともできます。

JPEG・PNG・WebP・BMP・GIF・TIFFの最初のフレームを使います。
スマホ写真の向きを補正し、最初の画像を基準に最大1280×1280pxの共通キャンバスへそろえます。
縦横比が違う画像は、余白を付けるか中央を切り抜く方法を選べます。余白は透明・白・黒です。
元の画像にある余白を自動で取り除く機能ではありません。

仕上がり
FPSは0.1～100。大きいほど速く再生します。50を超えるとブラウザーなどで指定どおり再生されない場合があります。
最大幅・高さは各1600pxまで、0は自動です。両方指定すると縦横比が変わる場合があります。
繰り返しは-1が1回、0が無限、正の数は指定回数です。往復再生は画像を並べる場合に使えます。
品質は1～100。速度優先・仕上がり優先、動きの品質・圧縮の品質、固定色16色、半透明の背景色も調整できます。
色は6桁のHEX（例：FFFFFF）。固定色はカンマ区切りで指定します。

既存GIF・Y4M
入力方法を「既存GIFを変換」にすると、1つのGIFを別名で再保存できます。
サイズ・品質・速度倍率・繰り返しを指定できます。GIFではFPS設定を使わず、速度倍率で変えます。
再圧縮すると画質が落ち、コマ数や時間が変わる場合があります。サイズ縮小などが必要な場合に使ってください。
詳細入力のY4Mは8bitの420・420jpeg・420mpeg2・420paldv・422・444に対応します。
Y4MではFPSによるコマの間引き、速度倍率、色空間指定ができます。白黒・10bit以上には対応しません。
MP4・MOV・AVIなどは読み込みません。FFmpegは同梱していません。

制限
画像は各25 MiB・1200万画素、入力合計256 MiB・1億2000万画素までです。
既存GIF・Y4Mは各300フレームまで。Y4Mは2048×2048px以内です。
作成結果も300フレーム・合計1億2000万画素・1600×1600px以内・10分・256 MiBまでです。
大きい画像を多数使う場合や往復再生では、出力が上限を超えることがあります。
処理は5分、一時ファイルは512 MiBまでです。十分な空き容量を用意してください。
失敗・停止した作業中のファイルは保存しません。既存のファイルは上書きしません。
リンク・ジャンクションは扱いません。
GIFの形式上、色数・透過・時間の精度に制限があります。完全な元画質の保持や容量の縮小は保証しません。
プレビューは目安で、再生中は確認用に繰り返します。保存したGIFの繰り返し設定とは別です。
コード署名はありません。
