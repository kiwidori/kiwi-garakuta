きういYAML整形 0.1.0

Windows 11 x64 / ZIPを展開して KiwiYamlfmt.exe を起動してください。
元ツール: yamlfmt v0.21.0 / https://github.com/google/yamlfmt (Apache-2.0)
このソフトは非公式のGUIです。
ソース: https://github.com/kiwidori/kiwi-garakuta/tree/main/apps/kiwi-yamlfmt
サイト: https://kiwi-garakuta.pages.dev/tools/kiwi-yamlfmt/
問い合わせ: https://x.com/kiwi_dori

入力欄にYAMLを貼り付けるか、ファイル・フォルダーを追加します。
操作を選び、必要な整形設定を指定して「実行」を押してください。
テキストの整形結果はYAMLとして保存できます。
ファイルの整形は一時コピーで行います。内容が変わったファイルだけZIPに入ります。
変更がなければZIPは空になります。元ファイルへの自動上書きは行いません。
「差分を表示」は元と整形結果を比較します。「整形チェック」は差分があると終了コード1になります。
整形チェックの差分レポートも保存できます。不正なYAMLのエラーとは別に表示されます。

整形設定の空欄は設定ファイル、未指定なら元ツールの既定値を引き継ぎます。
「設定ファイル」タブでYAML/JSON設定を読み込み・編集・保存できます。
グローバル設定は読み込むボタンで明示的に取り込みます。自動検索はしません。
KYAMLではBasic用の整形設定を空欄にしてください。
対象パターン・除外パターンは一時コピー内の相対パスで指定します。
フォルダーを1つ追加すると、その中身がパターンの基準位置になります。
複数の対象は共通の親を基準に相対構造を保持します。
gitignore方式では、パターンが書かれた対象内のファイル名を指定してください。
空欄なら yamlfmt.patterns を使います。gitignore方式は一致するファイルを含め、!で除外します。
絶対パス・対象外への .. ・リンク・ジャンクションは扱えません。

メニュー「詳細機能」では元ツールのオプションとヘルプを利用できます。
詳細機能は差分モードを強制します。書き換えの代わりに通常画面のZIP保存を使ってください。
標準入力の整形は -in オプションで行えます。
元ツールのライブラリ拡張・Docker・コマンドのパイプはこのGUIの機能ではありません。

処理は300秒、テキスト2 MiB、設定128 KiB、対象2000ファイル/2000フォルダー・合計64 MiB、
出力とエラー合計16 MiB、結果ZIP16 MiBまでです。選択したフォルダーはYAML以外も含めコピー上限の対象です。
一時コピーと結果はローカルの一時フォルダーを使い、処理後に削除します。ネット送信は行いません。
エラー継続を選んだ場合、不正なファイルは処理されず、一部の結果だけになることがあります。
YAML指示行の退避・復元と最大行幅は上流の制限を引き継ぎます。構文やコメント表記が変わるため結果を確認してください。
全設定の組合せを検証したものではありません。実行ファイルにコード署名はありません。
上流・Go依存物・PyYAML/LibYAML・Python/Tcl/Tkのライセンスを同梱しています。
