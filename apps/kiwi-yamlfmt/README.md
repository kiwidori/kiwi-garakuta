# きういYAML整形

YAMLの整形・差分表示・整形チェックを画面から操作できます。[yamlfmt v0.21.0](https://github.com/google/yamlfmt/releases/tag/v0.21.0)の非公式GUIです。

[使い方とダウンロード](https://kiwi-garakuta.pages.dev/tools/kiwi-yamlfmt/)

ZIPを展開し、`KiwiYamlfmt.exe`を起動してください。Windows 11 x64向けです。

入力欄へYAMLを貼り付けるか、ファイル・フォルダーを追加します。インデント・改行・空行・引用符・配列表記を指定でき、KYAMLにも変換できます。設定ファイルの読み込み・編集・保存、globやgitignore方式での対象選択にも対応します。

元ファイルは書き換えません。テキストの整形結果はYAMLとして、ファイルは**内容が変わったものだけ**ZIPとして保存します。整形チェックの終了コード1は、差分がある場合と構文エラーの場合があります。画面に表示された内容を確認してください。

処理は300秒、テキスト2 MiB、設定128 KiB、対象2000ファイル・2000フォルダー・合計64 MiB、出力と結果ZIPは16 MiBまでです。設定は明示的に読み込み、元ツールの自動検索は使いません。対象外へのパターン・リンク・ジャンクションは扱えません。詳しい制限は配布内のREADMEを参照してください。
