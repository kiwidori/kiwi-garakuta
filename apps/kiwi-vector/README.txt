きういベクター工房 0.1.0

ロゴ・線画・イラストなどをSVGへ変換する、Windows 11 x64用の無料ソフトです。
写真の画質を復元したり、文字を編集可能なフォントへ変換したりする機能ではありません。

使い方
1. ZIPをすべて展開し、KiwiVector.exeを起動してください。nativeフォルダーも必要です。
2. 「画像を選ぶ」でPNG・JPEG・WebP・BMP・TIFF・GIFを選びます。
3. おすすめ設定の「白黒」「イラスト」「写真」を選び、「設定を適用」を押します。必要に応じて色・輪郭・点の除去などを調整できます。
4. 「選んだ1枚をSVG保存」で、新しい.svgファイルへ保存します。「すべて一括保存」は、新しいフォルダーへまとめて保存します。
5. 「SVGをブラウザで見る」で結果を開き、拡大して輪郭を確認してください。SVGテキストのコピー、保存先を開く操作もできます。

調整できる項目
カラー／白黒、形の重なり方（スタック／カットアウト）、輪郭の形（曲線／多角形／ピクセル）、小さな点の除去、色の精度、色のまとめ具合、角の判定、線分の長さ、曲線を分ける角度、座標の小数桁数。
「背景」は白に合成する設定が標準です。カラーでは透明な部分を使う設定も選べます。半透明は白に合成し、完全に透明な部分のみ背景として扱います。白黒は白い背景で処理します。

制限
元画像・既存のSVGは上書きしません。処理はPC内だけで行い、画像をサーバーへ送りません。
入力は1～20枚、各128 MiB・800万画素・各辺8,000px、合計512 MiBまでです。GIF・TIFFは先頭の1枚だけを使い、EXIFの向きを補正してから変換します。
一括処理は5分、SVGは1枚32 MiB・合計128 MiB・輪郭100,000個までです。出力サイズは短い間隔で監視するため、一時的に上限を超える場合があります。
SVGのコピーは1 MiBまでです。大きいSVGは保存したファイルを利用してください。
輪郭を近似する変換です。色・形・透明部分の見え方が元画像と異なる場合があります。写真や細かな模様ではSVGが大きくなることがあります。色の精度や輪郭の設定を下げて調整してください。
ブラウザ表示は作成したSVGを対象とします。任意のSVGの読み込み・編集、アニメーション、文字認識には対応しません。1.0系の新機能は含みません。
Microsoft Visual C++ v14再頒布可能パッケージ（x64）が必要です。
https://learn.microsoft.com/ja-jp/cpp/windows/latest-supported-vc-redist
