# きういActions点検

GitHub Actionsのワークフローを、実行前に点検するWindows用ツールです。actionlint v1.7.12を同梱しています。

## 使い方

1. ZIPを展開し、`KiwiActionsCheck.exe`を起動します。
2. YAMLを入力欄に貼り付けるか、ファイル・フォルダーを追加します。リポジトリのフォルダーを選ぶと`.github/workflows`を探します。
3. 「ワークフローを点検」で実行し、指摘を確認します。終了コード1は指摘ありを表します。
4. 「結果を保存」でレポートを保存します。JSONやGoテンプレートによる書式も選べます。複数リポジトリは別々に点検し、JSONでは指摘の一覧をまとめます。

## 設定

「設定YAML」では独自ランナーのラベル、設定変数、パスごとの無視条件を指定できます。設定ファイルを読み込み・保存でき、「既定の設定YAMLを作成」でひな形を作れます。生成だけではリポジトリへ書き込みません。

ShellCheckとpyflakesは同梱していません。使う場合は「外部チェッカー」で各実行ファイルの絶対パスを指定してください。空欄では呼び出しません。「詳細機能」では追加の表示・診断オプションを使えます。

## 制限

- ワークフローやスクリプトは実行しません。元ファイルを書き換えません。ローカルアクションや再利用ワークフローの確認では、関連ファイルも読みます。
- 設定の自動検索は行いません。利用する設定は画面で指定してください。
- 入力テキストは2 MiB、設定は128 KiB、ファイルは1つ20 MiB・合計64 MiB・200件、探索は2000フォルダーまでです。
- 1回300秒、出力合計16 MiB、引数は256個・64 KiBまでです。リンクとジャンクションは入力に使えません。全オプションの組合せを検証したものではありません。
- Windowsの出力取り込みでは、色を指定しても元ツールが色なしで出力する場合があります。
- 点検の結果はGitHub上での実行成功を保証しません。実行ファイルにコード署名はありません。
