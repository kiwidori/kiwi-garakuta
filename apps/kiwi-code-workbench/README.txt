きういコード・文書作業場 0.1.0 / Windows 11 x64

ZIPを展開し、KiwiCodeWorkbench.exeを起動してください。
コード閲覧・シェル整形・コード資料・Markdown閲覧を用途から選べます。
入力テキストと対象一覧を共有し、用途別の設定は起動中に保持します。

シェルを整形した後「整形結果をコード閲覧へ」で色付き表示に渡せます。
コード資料をMarkdown形式で生成した後「生成資料をMarkdown閲覧へ」で文書表示に渡せます。
移送時は共有入力と対象指定を置き換えるか確認します。切替や移送では自動実行しません。
ファイルを選んで「ファイルのフォルダーを資料対象へ」を押すと、その親フォルダーを資料の対象にできます。
資料はフォルダー1つを使います。コードとMarkdownのファイル閲覧はファイル1つを使います。
シェル整形では複数ファイル・フォルダーと整形結果ZIPにも対応します。

コード閲覧は500行ずつの表示・言語指定・3テーマ・装飾付き/プレーン保存に対応します。
コード資料はinclude/exclude・Git差分/履歴・トークン情報・独自テンプレート・変数を指定できます。
Markdownは貼付け・ファイル・URL/README、テーマ・独自JSONスタイル・折返し設定に対応します。
各ツールの追加設定と同梱ヘルプは「詳細機能」から利用できます。

シェルスクリプトやHTML/JavaScriptは実行しません。入力ファイルの自動書き換えは行いません。
コード資料はAIへ送信しません。URLによるMarkdown閲覧では指定先へ通信します。
整形された単一シェル本文とMarkdown形式の生成資料だけを移送できます。
差分・AST JSON・一覧・ヘルプ・診断・ZIP・装飾済み表示は本文として移送できません。
テキスト入力と移送はUTF-8で2 MiB、NUL/ANSI制御を含む結果は移送できません。
コード閲覧はファイル10 MiB・出力2 MiB・15秒・1回500行。Markdownファイルは2 MiBです。
その他は1回300秒・出力16 MiB。シェル一括処理は2,000ファイル・合計64 MiB、保存ZIP16 MiBです。
資料の入力設定.c2pconfigを継承するため、画面でfalseにしても設定のtrueを解除しない項目があります。
トークン数は選んだencodingによる目安です。生成された差分資料は適用可能なパッチではありません。
閲覧対象にフォルダーを指定するとエラーになります。通常の対象指定はリンク/ジャンクションを扱いません。
端末用TUI・ページャー・外部エディター等は対象外です。詳細画面は用途切替で初期化されます。
全ての文書・式・オプションの組合せは保証しません。実行ファイルは未署名です。
