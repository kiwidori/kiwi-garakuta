きうい動画・GIF工房 0.1.0
Windows 11 x64 / ZIP版

動画の形式変換とGIFづくりをまとめた無料ソフトです。
動画の短い区間を取り込み、並べ替え・速度・品質を調整してGIFにできます。
FFmpegとgifskiを利用した非公式GUIです。

使い方
1. ZIPをすべて展開し、KiwiMediaWorkbench.exeを起動します。
2. 動画を扱う場合は、初回に「動画エンジンを準備」を押します。
   FFmpeg公式サイトが案内するgyan.devのGitHubから約100MBを取得します。
   展開後は約273MB。従来の動画工房で取得済みなら同じエンジンを使います。
3. 動画を選び、「区間・映像」で開始・終了や回転・切り抜きを設定します。
4. 「選択動画の区間をGIFへ」でGIF編集を開きます。
   終了0は開始から最大10秒。10秒・100コマ・1280×720pxまで取り込みます。
   取り込みFPSは0.1～30で、区間の長さとの積が2～100コマになるよう指定します。
5. GIF画面で順序・FPS・品質を調整し、「保存名を選んでGIFを作る」で保存します。
   取り込んだ画像列は閉じるまでの一時ファイルです。残す場合はGIFとして保存してください。

変換結果の一覧で1件選び「選択した保存結果の先頭をGIFへ」も使えます。
こちらは先頭から最大10秒、追加の回転・切り抜きなしで取り込みます。
音声だけのファイルや保存した静止画は動画取り込みの対象ではありません。
取り込みでGIFの入力一覧を置き換える際は確認します。元ファイルは削除しません。

動画の変換
MP4（H.264/H.265）・WebM（VP9）、サイズ・画質・FPS、開始/終了、
自動回転・手動回転・上下左右反転・切り抜き、PNG/JPEG静止画に対応。
MP3/M4A/WAV/FLAC/Opus、音声トラック指定、消音・音量・ラウドネス調整、
撮影情報の除去、最大5件の一括保存、情報・静止プレビューも利用できます。
動画は再圧縮します。必ず小さくなる保証や、無劣化の切り出し機能はありません。
H.265・VP9は再生機器の対応が必要。音声は48kHz・ステレオになります。
WAV/FLACにしても失われた音質は復元しません。音量は保存後に確認してください。

GIFの編集
「画像・GIF・Y4Mを編集」では、動画なしでも画像を並べて作成できます。
JPEG/PNG/WebP/BMP/GIF/TIFFの先頭フレーム、EXIFの向き補正、自然な名前順、
上下移動・除外、余白/切り抜き、透明/白/黒背景、幅・高さ、往復再生、
FPS・品質・繰り返し、速度優先/仕上がり優先、動き/圧縮品質、固定色16色、
半透明背景色、既存GIFのサイズ/速度、Y4Mと色空間、作成後の再生に対応。
結果のコピー・TXT保存・保存先を開く操作も使えます。
画像の速度はFPSで調整。速度倍率は既存GIF/Y4M用、往復は画像列用です。

制限
動画入力：MP4/M4V/MOV/MKV/WebM/AVI/MPG/MPEG/TS/MP3/M4A/WAV/FLAC/OGG/Opus。
1件2 GiB・2時間、4096px・900万画素・120fps。映像変換はSDR/8bit向け。
HDR/10bit映像変換は非対応、音声保存は可能。字幕・チャプター等は引き継ぎません。
動画出力1 GiB・処理30分、プレビュー60秒。入力サイズに加えて1 GiBの空きが必要。
動画からGIFへの取り込みは120秒・100枚・合計256 MiBまで。
手動の画像列は2～100枚、各25 MiB/1200万画素、合計256 MiB/1億2000万画素。
GIF/Y4Mは300フレーム・合計1億2000万画素。Y4Mは2048×2048以内の8bit420/422/444。
GIF出力は1600×1600px・10分・256 MiB、作成5分、一時領域512 MiBまで。
手動画像/Y4MのFPSは0.1～100。50超は再生側によって速度が変わる場合があります。
GIFは再圧縮で画質が落ちる場合があります。ループや速度は再生側にも依存します。
動画結合・字幕焼き込み・録画・配信・GPU処理・全CLIオプションには非対応です。
処理は同時に1件。停止・終了時は処理の終了を待ちます。保存済みの出力は残ります。
入力・出力のリンクやジャンクションは扱いません。既存ファイルは上書きしません。

GIFの実行にはMicrosoft Visual C++ v14 x64ランタイムが必要です。
必要な場合はMicrosoft公式の再頒布可能パッケージを手動で準備してください。
https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist
初回の動画エンジン取得以外で素材を送信しません。GIFエンジンは同梱しています。
