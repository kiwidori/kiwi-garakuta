きういHTTPビュー 0.2.1

以下は通常画面の説明です。追加オプションは末尾の「詳細機能」を参照してください。

Windows 11 x64向けの無料ツールです。ZIPを展開してKiwiHTTP.exeを起動します。
http:// または https:// で始まるURLを入力し、GETまたはHEADを選んで「送信」を押します。
応答のステータス・ヘッダー・本文をテキストで確認し、必要ならコピーできます。
URLは入力した接続先へ送信します。応答やURLには個人情報が含まれる場合があります。
GET/HEADでも接続先の仕様によっては操作が発生するため、確認するURLを選んでください。

リダイレクトは追跡しません。認証・カスタムヘッダー・送信本文の指定には対応しません。
URL内のユーザー名・パスワードは使えません。ローカルPCやLAN内の接続先も指定できます。
証明書の検証は有効です。環境のプロキシ設定が適用されます。
URLは2048文字まで、応答は512 KiBまで、処理は15秒までです。
UTF-8以外の本文は文字化けする場合があります。バイナリを保存する機能はありません。
HTMLやスクリプトは実行せず、文字として表示します。

元ツールxh: https://github.com/ducaale/xh
このソフトはxh開発者の公式製品ではありません。xhのMITライセンスはxh-LICENSE、GUIのライセンスはLICENSEを参照してください。
ソース: https://github.com/kiwidori/kiwi-garakuta/tree/main/apps/kiwi-http
問い合わせ: https://x.com/kiwi_dori
現時点の実行ファイルにはコード署名がありません。環境によってはMicrosoft Visual C++ Redistributableが必要です。


詳細機能（0.2.1）
メニュー「詳細機能」→「開く」で、元ツールの追加オプションを組み立てられます。
候補を選び、値・ファイル・フォルダー・標準入力を指定して実行してください。
引数は1項目につき1個です。スペースを含むパスを引用符で囲む必要はありません。
順番は上下ボタンで変更できます。複数の値を取るオプションは値を別項目として追加してください。
同梱ヘルプ・プリセット・終了コード・出力保存に対応しています。
結果はテキスト表示です。標準出力を保存すると元のバイト列を保持します。
シェルのパイプやリダイレクト、対話式の端末機能は使いません。
出力合計16 MiB、標準入力2 MiB、1回300秒、引数256個までです。
詳細機能の制限: https://github.com/kiwidori/kiwi-garakuta/blob/main/docs/upstream-feature-audit.md
書き込み先・入力ファイル・通信先を確認してから実行してください。
通常画面の機能・表示上限は従来どおりです。
