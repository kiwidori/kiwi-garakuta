きういHTTPビュー 0.1.0

Windows 11 x64向けの無料ツールです。ZIPを展開してKiwiHTTP.exeを起動します。
http:// または https:// で始まるURLを入力し、GETまたはHEADを選んで「送信」を押します。
応答のステータス・ヘッダー・本文をテキストで確認し、必要ならコピーできます。
URLは入力した接続先へ送信します。応答やURLには個人情報が含まれる場合があります。
GET/HEADでも接続先の仕様によっては操作が発生するため、確認するURLを選んでください。

リダイレクトは追跡しません。認証・カスタムヘッダー・送信本文の指定には対応しません。
URL内のユーザー名・パスワードは使えません。ローカルPCやLAN内の接続先も指定できます。
証明書の検証は有効です。環境のプロキシ設定が適用されます。
URLは2048文字まで、応答は512 KiBまで、処理は15秒までです。
UTF-8以外の本文は文字化けする場合があります。バイナリを保存する機能はありません。
HTMLやスクリプトは実行せず、文字として表示します。
