きうい画像OCR 0.1.0
スクリーンショットや写真の文字を読み取り、コピーできる文章にします。
RapidOCRを利用した非公式GUIです。
Windows 11 x64用。ZIPをすべて展開し、KiwiOCR.exeを起動してください。
_internalフォルダーを移動・削除しないでください。
Microsoft Visual C++ v14 再頒布可能パッケージ（x64）が必要です。
https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist

1. 「画像を追加」で読みたい画像を選びます。フォルダー直下からも追加できます。
2. 必要なら画像を90度回転したり、ドラッグして読む範囲を選びます。
3. 「選んだ画像を読む」（F5）を押します。「すべて読む」で20件まで続けて処理できます。
4. 読み取った文章を確認・修正し、コピーまたはTXTへ保存します。

行を選ぶと画像の対応箇所を強調します。単語・文字の位置も取得できます。
「文字の位置だけ」「1行の文字を読む」「行の上下を調べる」も選べます。
上下の判定・補正は文字行の0度と180度です。ページの90度回転の自動判定ではありません。
詳細設定でCPUスレッド数、検出のしきい値・拡張率、前処理などを調整できます。
認識時の結果をCSV・JSON・Markdown、位置付き画像をPNGへ保存できます。
編集後の文章はコピー・TXTとJSONのedited_textへ反映します。CSV・Markdown・位置は認識時の結果です。
既存ファイルは上書きしません。別名で保存してください。元画像は変更しません。
画像ファイルを実行ファイルへ渡して起動することもできます。

処理はPC内で行います。モデル同梱のため追加ダウンロードは不要です。
日本語・英語などに対応しますが、手書き、縦書き、複雑な段組みや不鮮明な画像では誤認識があります。
認識結果は必ず確認してください。表のセル構造を復元するソフトではありません。
PNG/JPEG/WebP/BMP/GIF/TIFFの最初のフレームのみ。各25 MiB・2,000万画素まで。
長辺2,000px以内へ縮小して処理します。小さな文字は、先に画像編集ソフトで切り出すと読みやすくなります。
1画像2分、一括10分、結果32 MiB・1万行、位置付きPNG16 MiBまでです。
停止・失敗時も、処理済みの画像の結果は残ります。
PDF、カメラ、自動スクリーンキャプチャー、Web画像取得、GPU、モデルの切り替えには対応していません。
コード署名はありません。
