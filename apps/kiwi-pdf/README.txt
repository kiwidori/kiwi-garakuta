きういPDF 0.1.0 / Windows 11 x64

PDFの結合・ページの取り出し・分割・回転を、PC内だけで行う無料ソフトです。
ZIPを展開してKiwiPdf.exeを起動し、PDFを追加してください。
結合は一覧の順番で行います。ほかの操作は選択した1件が対象です。
ページ欄は空欄で「すべて」、1,3-5などでページを指定できます。5-1は逆順です。
PDFごとに入力パスワードを設定でき、ページ数も調べられます。
元のPDFや保存先にあるファイルは上書きしません。

分割したPDFはZIPへまとめます。容量の最適化・パスワードの設定/解除・検査にも対応しています。
画像の画質を落とす設定は初期状態でオフです。容量が減らない場合もあります。
通常のPDF出力では、読み込んだPDFのパスワード設定を引き継ぎます。
解除する場合は、パスワードを入力して「パスワードを解除」を選んでください。
新しいパスワード設定はAES-256です。パスワードは自動保存しません。

必要なもの: Microsoft Visual C++ v14 再頒布可能パッケージ (x64)
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist
GPUは不要です。Microsoftのランタイムは同梱していません。
1件200 MiB・合計500 MiB・50件まで。出力300 MiB、1回180秒、分割は500件まで。
文章の直接編集・OCR・署名の追加には対応していません。加工により既存の電子署名が無効になる場合があります。
現時点の実行ファイルにはコード署名がありません。

「詳細設定」ではqpdfのJob JSONで、PDFを重ねる・添付・注釈やフォーム・メタデータ・構造の確認などを指定できます。
元ファイルへの上書き、外部のジョブ設定、JSONからの復元、外部ストリームファイルへの書き出し、弱い暗号化には対応していません。

qpdfの非公式GUIです。元ツールの開発者による公式製品ではありません。
