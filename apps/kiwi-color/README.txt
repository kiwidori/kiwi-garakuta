きうい色変換 0.1.0

Windows 11 x64向けの無料ツールです。ZIPを展開してKiwiColor.exeを起動します。
HEX色コード、RGB・HSL表記、英語の色名を入力して「変換」を押します。
例: #66bb44 / rgb(102, 187, 68) / hsl(103, 46.7%, 50.0%) / red
pastelで変換したHEX・RGB・HSLと色見本を表示します。各表記は「コピー」でコピーできます。
「色を選ぶ」から色を選んだ場合も、「変換」を押して結果を確認してください。

不透明な色のみ対応し、RGBA・HSLA・8桁HEX・transparentは対象外です。
RGB・HSLは6桁HEXにそろえた色から算出します。数値の丸めで表記が変わる場合があります。
入力は128文字、処理は15秒までです。色見本はディスプレイ設定などによって見え方が変わります。
画像や画面から色を読み取る機能はありません。ファイル操作や外部への送信は行いません。
