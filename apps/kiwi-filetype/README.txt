きういファイルしらべ 0.1.0
Windows 11 x64 / インストーラーなしZIP

拡張子がない・間違っていそうなファイルを、内容から調べます。
種類、候補拡張子、MIME、分類、推定スコアを確認できます。
元のファイルは変更しません。自動で開いたり、名前を変更したりしません。

使い方
1. ZIPをすべて展開してKiwiFileType.exeを起動します。
2. Microsoft Visual C++ v14再頒布可能パッケージ（x64）が必要です。
3. 初回のみ「エンジンを準備」を押します。公式MagikaのWindows版約10 MBを取得します。
   LocalAppData/KiwiFileTypeへ保存します。初回の取得後、判定はPC内で行います。
4. ファイルまたはフォルダーを選び、「種類を調べる」を押します。
   フォルダーの下まで調べる場合は「下の階層も調べる」を選びます。
5. 結果の表示・保存形式を選び、「表示を更新」または「結果を別名で保存」を押します。
   同名の保存先には連番を付け、既存ファイルを残します。

その他の入力・出力
「入力した文章」では下の欄のUTF-8テキストを調べます。
「ファイルを標準入力へ」では、入力一覧で選んだ1件のバイト列を使います。
CSV、JSON、JSONL、説明、MIME、ラベル、書式指定のTXTを保存できます。
JSON・JSONLは元エンジンの判定情報を保持します。CSVはUTF-8 BOM付きで、
表計算ソフトの式に解釈される先頭記号には引用符を付けます。
書式指定には %p %l %d %g %m %e %s %S %b %% を使えます。
同梱ヘルプに各記号の説明があります。書式指定は表示用のため数値表記等が元CLIと異なります。

制限
Google Magika CLI 1.1.0の非公式GUIです。判定は推定で、必ず正しいとは限りません。
推定スコアはファイルの安全性や正解の保証を示しません。
ウイルス検査、破損ファイルの修復、ファイル名変更、アーカイブ内部の展開判定は行いません。
複合形式や破損ファイルでは結果が実際の用途と異なる場合があります。
選択は200件、展開後500ファイル、各2 GiB・合計20 GiBまで。
フォルダーは6000項目・32階層まで。下の階層の調査は初期状態では無効です。
標準入力は2 MiB、書式500文字、保存結果16 MiBまでです。
リンク・ジャンクション・ネットワークパスは扱いません。アクセスできない項目等は除外します。
判定は50件ずつ・各60秒まで、同時に1処理です。途中で停止すると部分結果を表示しません。
端末のANSI色付けは使いません。任意のCLI引数、別モデル、予測閾値の設定はありません。
画面の結果表示は先頭500000文字までですが、保存には結果全体を使います。
結果のレポートには選択したファイルのパスが含まれます。共有前に内容を確認してください。
実行ファイルにはコード署名がありません。
