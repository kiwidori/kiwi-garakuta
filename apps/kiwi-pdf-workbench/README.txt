きういPDF作業場 0.2.0
Windows 11 x64 / ZIPをすべて展開してKiwiPDFWorkbench.exeを起動してください。

PDFの結合・取り出し・分割・回転・最適化・パスワード・詳細設定を使えます。
選択したPDFと作成済みのPDFは、表示・PNG画像・テキスト保存へそのまま渡せます。
画像エンジンは初回のみ公式MuPDF 1.28.5の約90MiBを取得し、SHA-256を照合します。
PDF編集は各200MiB、画像化は32MiB・指定100ページまで。
暗号化PDFの画像化は、先に解除したコピーを作ってから行ってください。
上書きはしません。大切なPDFはバックアップしてください。

Microsoft Visual C++ v14 (x64)が必要です。
詳細・制限: https://kiwi-garakuta.pages.dev/tools/kiwi-pdf-workbench/
ソース: https://github.com/kiwidori/kiwi-garakuta/tree/main/apps/kiwi-pdf-workbench
問い合わせ: https://x.com/kiwi_dori のDM
GUIはMIT。上流・依存物・ランタイムのライセンスは同梱文書をご覧ください。

文字・ロゴを重ねる
選択したPDFまたは作成PDFをスタンプ画面へ渡せます。日本語の文字、ロゴ、別PDF、ページ番号を追加できます。
初回のみ公式pdfcpu 0.16.4 Windows版約7 MBを取得します。
保存したスタンプPDFは、そのまま表示・画像化、または編集一覧への追加ができます。
スタンプは元PDF32 MiB・1000ページ、画像等16 MiB、出力64 MiBまで。暗号化・電子署名付きPDFは対象外です。
日本語は画像になるため文字選択・検索はできません。透かしはコピー・編集を防ぐものではありません。
背面の印はスキャン画像等に隠れます。スキャンPDFには手前の印をご利用ください。
詳細: stamp-engine/README.txt。各画面は処理を共有し、同時には実行しません。
