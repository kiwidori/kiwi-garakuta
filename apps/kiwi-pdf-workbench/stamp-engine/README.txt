PDFスタンプ操作の説明（PDF作業場）
Windows 11 x64 / ZIP版

PDF作業場の文字・ロゴ画面で、初回のみ「スタンプエンジンを準備」を押します。
公式pdfcpu 0.16.4（約7 MB）を取得します。以後の処理はPC内で行い、PDFを送信しません。
元のPDF、重ねる内容、位置・幅・回転・濃さを選び、保存先フォルダーを指定します。
既存のファイルは上書きせず、同名なら連番で保存します。

文字・ロゴ・PDF
・日本語の文字はWindowsの游ゴシックを使って透過PNGに描いてから重ねます。
  200文字・4行まで。改行は入力欄に \n と書きます。画像なので文字の選択・検索はできません。
  絵文字や游ゴシックにない文字は正しく描けない場合があります。
・欧文モードは半角英数字・記号500文字まで。%p は現在ページ、%P は総ページ数です。
・画像は単一フレームPNG/JPEG/WebP/TIFF、16 MiB・2,000万画素までです。
・別PDFの指定ページ、またはそのPDFを先頭から順番に重ねられます。
  順番モードのページ数が元のPDFに足りない場合は上流ツールの規則で最後のページを繰り返します。
・背面の透かしはページ全面の画像などに隠れます。スキャンPDFには手前のスタンプを使ってください。
・更新・削除はpdfcpuが認識する既存の印が対象です。手作業の文字・一般の注釈などを消す機能ではありません。

詳細設定（欧文・画像・PDF）
JSONオブジェクトで指定します。例: {"offset":[0,20],"fillcolor":"#336699"}
offset: 2個の数値、-1000～1000pt。
fillcolor / strokecolor / backgroundcolor: #336699形式の色。
fontname: PDF標準14フォント。Helvetica、Times-Roman、Courierと各太字・斜体、Symbol、ZapfDingbats。
points: 整数1～300。通常の相対指定では最終的な大きさが幅に合わせて調整されます。
aligntext: l/c/r/j、rendermode: 0/1/2、margins: 1～4個の0～1000の配列、border: 0～100。
色・フォント・文字配置・枠は欧文テキスト用です。日本語画像化では詳細設定は使えません。
任意のCLI引数、ユーザーフォントの追加、外部設定の読み込みはありません。

制限
元PDF32 MiB、重ねるPDF16 MiB、各1000ページ、出力64 MiBまで。
対象ページは空欄（全部）、1-3,5形式、odd（奇数）、even（偶数）です。
暗号化・電子署名付きPDF、ネットワークパス、リンク・ジャンクションは扱いません。
処理180秒、検証30秒、同時1件。停止すると未保存の出力を破棄します。
PDFの修復、墨消し、コピー・編集の禁止、電子署名の保持を行うものではありません。
元PDFのリンク・注釈・スクリプト等を無害化する機能もありません。
保存後にPDFビューアーで文字・ロゴの表示とページ内容を確認してください。
保存後は「保存PDFを表示・画像化」で見た目を確認できます。

pdfcpuの非公式GUIです。結合・分割・並べ替えはメイン画面で行います。

PDF作業場版の追加設定
詳細JSONのscale_modeはrel（ページに対する割合）またはabs（絶対倍率）です。
absでは大きさ0.01～100、欧文のpointsは整数1～300で指定できます。
diagonalは1（右上がり）または2（右下がり）で、回転欄に代わって使われます。
fontnameはPDF標準14フォントを使えます。Symbol・ZapfDingbatsでは記号フォントの字形になります。
borderは数値のほか、オブジェクト例 {"width":2,"round":true,"color":"#336699"} に対応します。背景色も指定してください。
PDFを順に重ねるとき、開始欄を2:3とすると重ねるPDFの2ページ目から元PDFの3ページ目以降へ適用します。
コロンを含まない数字は指定ページモードでのみ使い、順番モードでは両方の先頭からです。
