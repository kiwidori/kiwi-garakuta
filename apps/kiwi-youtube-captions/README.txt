きういYouTube字幕 0.1.0
Windows 11 x64 / インストーラー不要
ZIPを展開し、KiwiYoutubeCaptions.exeを起動してください。

YouTubeの字幕を読んだり、文字や時刻で探したり、ファイルへ保存できます。
1. YouTubeのURLまたは動画IDを入力し、「字幕一覧を取得」を押します。
2. 手動・自動の字幕から元の言語を選びます。対応する字幕では翻訳先も選べます。
3. 「字幕を取得」で表示します。文字検索と開始・終了秒で絞り込めます。
4. TXT・SRT・VTT・JSON・CSVから保存形式を選びます。
   全行、または検索に一致した全行を保存できます。

選択した字幕の時刻をYouTubeで開けます。表示中や選択した行はコピーできます。
「一括保存」では最大20動画を処理し、優先する言語、手動・自動の条件、
翻訳先を指定できます。any=両方、manual=手動のみ、generated=自動のみです。
1動画1ファイルで保存し、既存ファイルは上書きしません。
「デモ字幕」はサンプル文章を表示し、ネットワークには接続しません。

翻訳はYouTubeが提供するものを使います。翻訳先が表示されない字幕では使えません。
元字幕の手動・自動の区分は、翻訳結果を人が作成したという意味ではありません。
APIキーやPythonのインストールは不要です。HTTP/HTTPSプロキシも任意で指定できます。
プロキシの認証情報を設定ファイルや保存結果に残しません。

制限
・字幕が非公開、削除済み、年齢確認・ログインが必要な動画は取得できません。
・YouTubeの接続制限や仕様変更により、公開字幕でも取得・翻訳できない場合があります。
・このソフトは動画や音声をダウンロードせず、字幕のない動画の文字起こしは行いません。
・一覧表示は最大1,000行。保存は全行または検索に一致した全行で、表示上限に左右されません。
・1動画20,000行・5 MiB、HTTP応答8 MiB、1動画の取得90秒までです。
・「停止」は通信が終了するまで最大約15秒待つ場合があります。
・CSVでは数式として解釈される先頭文字にアポストロフィを付けます。
・コード署名はありません。
