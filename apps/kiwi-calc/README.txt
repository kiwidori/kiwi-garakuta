きうい単位計算 0.1.0 / Windows 11 x64 / インストール不要

Numbat v1.24.0の非公式GUIです。KiwiCalc.exeを起動して使います。
数値・元の単位・変換先を指定して、距離・速度・温度・情報量などを変換できます。
「プログラム」では複数行のNumbatコードを実行できます。変数・関数・物理量の型、
リスト・文字列、数学・統計・日時・数値解析などは式で指定します。
「計算例」から実行例を選び「例を入力」で試せます。複数の途中結果はprint()で出力します。
通常のファイル/式評価は最後の値を自動表示します。式自体の整形表示も選べます。

「スクリプト」ではUTF-8の.nbtファイルを1つ選びます。元ファイルをGUIが書き換えることはありません。
「追加式・引数」タブで、追加の-e式（1行1式）とスクリプト引数（1行1引数）を指定できます。
ファイルの後に追加式が評価されます。args()は上流の仕様によりGUIが渡すCLIオプションを含む
全引数を返します。ユーザーが追加した引数だけのリストではありません。
各実行は新しい計算状態です。「式を保存」で入力を.nbtへ、「結果を保存」で標準出力を保存できます。

「連続入力・REPLコマンド」は入力欄の行を同じ計算状態で処理します。
list units / list functions / list dimensions / list variables / info sin / help等を入力できます。
save、reset、quit等は上流REPLの動作に従います。saveは指定したファイルへ書き込みます。
計算後にREPLを使う場合は「実行設定」で有効にし、「追加式・引数」の連続入力欄へ記入します。
端末のキー操作、Tab補完、履歴のキー移動、実行途中に行を送る操作は提供していません。
REPLは履歴ファイルを作成する場合があります。REPLのエラーは終了コード0でも表示される場合があります。

初期状態ではユーザーconfig.tomlとinit.nbtを読みません。チェックを外すと上流の固定場所から読みます。
外部モジュールは上流の探索規則で読み込み、ユーザー/システムのモジュールが組込み版より優先されます。
--no-config/--no-initはこの探索を無効にしません。独立したサンドボックスではありません。
「設定テンプレート」で既定設定を表示し、「結果を保存」で任意先へ保存できます。
そのファイルを上流設定の場所へ配置する操作は手動です。--generate-configによる固定先への書込みはブロックします。
標準単位/Prelude無効、ANSI色、整形、起動表示、デバッグも選べます。
同梱Windows版は標準ライブラリとデバッグの併用で異常終了するため、デバッグにはPrelude無効が必要です。
詳細機能ではデバッグをブロックし、通常画面のチェックから利用します。
「詳細機能」メニューには追加の引数・ファイル・標準入力・ヘルプがあります。

通常の単位計算にはインターネット・AI・クラウドAPIは不要です。
通貨の記号を使うと上流が為替レートを取得します。REPLも既定設定では起動時に取得します。
通信・レート取得の成功や最新性を保証しません。通貨の専用画面はありません。
show()によるプロットは上流が外部ブラウザを開きます。グラフをこのGUI内へ埋め込みません。
標準ライブラリの各関数に個別の設定画面を用意しているわけではありません。

入力欄・連続入力2 MiB、追加式12,000バイト/120行、引数256個/64 KiB、
Windowsコマンド行30,000文字未満、1回300秒、標準出力と標準エラー合計16 MiB。
ファイルは上流が直接読み取り、入力欄の容量制限と異なります。
画面の結果表示は先頭128 KiB・256スタイルまで。全標準出力は保存できます。
実行ファイルは未署名です。停止で計算プロセスを終了しますが、上流が開いたブラウザ等は閉じません。
