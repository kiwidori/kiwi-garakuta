きうい画像工房 0.1.0
Windows 11 x64 / インストーラーなしZIP

写真をまとめて変換・リサイズする無料ソフトです。
ImageMagick 7.1.2-34を利用した非公式GUIです。

使い方
1. ZIPをすべて展開してKiwiImage.exeを起動します。
2. 初回のみ「画像エンジンを準備」を押します。公式GitHubから約12MBを取得します。
   Windows標準のtar.exeで展開し、ユーザーのLocalAppData/KiwiImageに保存します。
   ImageMagickの実行にMicrosoft Visual C++ v14 x64ランタイムが必要な場合があります。
3. 「画像を選ぶ」で写真を追加し、形式・サイズ・切り抜き・色を設定します。
4. 「プレビュー」で元画像と仕上がりを確認します。
5. 「すべて別名で保存」で保存先を指定します。元画像や既存ファイルは上書きしません。

対応
入力：JPEG / PNG / WebP / AVIF / HEIC・HEIF / BMP / TIFF / GIF。
出力：JPEG / PNG / WebP / AVIF / BMP / TIFF / GIF / ICO。
写真の向きの自動補正、倍率・枠内・中央切り抜き・縦横指定、回転・反転、
座標切り抜き、明るさ・コントラスト・鮮やかさ・ガンマ、シャープ・ぼかし、
モノクロ・セピア・色反転・明暗自動調整、メタデータ削除に対応します。
WebP可逆圧縮、JPEGプログレッシブ、白・黒・透明の背景を選べます。

制限
画像は1～20枚、各50 MiB、合計200 MiB、各辺8,000px・2,500万画素まで。
入力の先頭の1枚だけを使います。アニメーションや複数ページの維持はできません。
出力は1枚128 MiB・合計512 MiBまで。1枚約60秒、一括約10分が目安の上限です。
JPEGは透明非対応で白または黒に合成します。ICOは最大256pxです。
非可逆形式では画質が変わります。画質の指定は形式によって効き方が異なります。
PNGは8bit RGBA出力です。16bit/HDR/RAW現像、PDF・SVG、動画、文字入れ、
合成・レイヤー編集、アニメーション編集、全CLIオプションには対応しません。
初回のエンジン取得後は画像処理のための通信は行いません。画像のアップロードはありません。
写真の位置情報を取り除きたい場合は「メタデータを削除」を選んでください。
プロファイルも削除されるため、色味が変わる場合があります。
途中で停止・失敗したときも、保存済みの画像は残ります。
