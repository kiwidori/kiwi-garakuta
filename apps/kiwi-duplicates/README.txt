きうい重複チェック 0.1.0
Windows 11 x64 / インストーラーなし

ZIPを展開してKiwiDuplicates.exeを起動します。初回のみ「エンジンを準備」でfclones公式Windows版を取得します。
対象フォルダーを選んで「ファイルを調べる」。別のフォルダーも比べたいときは追加の対象を選びます。同じ場所や親子関係のある対象は指定できません。
サブフォルダーの深さ、サイズ、重複の最低件数を指定できます。「1つだけのファイル」は指定した対象と条件の中で一致するものがないファイルです。空ファイルを含める場合は最小サイズを0にします。
CSVには全結果の対象番号・相対パス・SHA-256を保存します。画面は先頭500件までです。検索結果は検索時点の状態です。

読み取り専用で、元ファイルを削除・移動・変更しません。似た写真や似た文章の判定はできません。
対象はファイルとフォルダー合計10,000件、検索ファイル各512 MiB・合計8 GiB、処理10分までです。512 MiBより大きいファイル、指定サイズ外、240文字を超えるパス、リンク・ジャンクション・クラウド専用ファイルは除外します。
ハードリンクの別名は重複サイズに数えません。表示する重複分のサイズはファイルサイズによる目安で、実際に空くディスク容量とは異なる場合があります。
ローカルドライブ向け。ネットワークパスは非対応です。

無料・非公式GUIです。元ツールの削除・リンク置換などの変更操作は提供しません。
