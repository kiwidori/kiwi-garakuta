# きういJSON式

JSON・YAMLを式で検索、集計、変換するWindows用ツールです。gojq v0.12.19を同梱しています。

## 使い方

1. ZIPを展開し、`KiwiJsonExpr.exe`を起動します。
2. データを入力欄に貼り付けるか、ファイルを追加します。
3. 式を入力して実行します。`.`は整形、`length`は件数、`.[]`は値の一覧です。画面下のボタンからも選べます。
4. 結果を確認して保存します。JSON・YAML・生テキストなどの形式を選べます。

入力の配列化、ストリーム入力、nullからの式実行、文字列・JSON・ファイル変数、位置引数に対応します。式ファイルやモジュールの検索フォルダーも指定できます。変数欄は名前と値のJSONオブジェクト、位置引数欄はJSON配列で入力してください。

## 制限

- 元ファイルを書き換えません。データをネットへ送信せず、OSのコマンドを実行しません。式からローカルの環境変数やモジュール・変数ファイルを読むことはできます。
- gojqの式はjqと完全互換ではありません。オブジェクトのキー順は保持しません。整数の加減乗算などでは大きな整数の精度を保ちますが、浮動小数点を使う関数は例外です。
- 終了状態の判定を有効にすると、false/nullは終了コード1、出力なしは4になります。構文エラーとは区別して表示します。
- 位置引数を使う場合、データは入力欄へ貼り付けてください。元CLIが残りの引数を位置引数として扱うため、入力ファイルとは併用できません。
- 入力テキスト2 MiB、1ファイル20 MiB・合計64 MiB・200件、式ファイル・変数ファイル各2 MiB、変数設定各128 KiBまでです。名前付き変数・位置引数は各100件、モジュール検索先は32件までです。
- 1回300秒、出力合計16 MiB、引数256個・64 KiBまでです。リンクやジャンクションは通常画面の入力に使えません。画面は出力の先頭約13万文字まで表示し、保存は出力全体を対象にします。
- NUL区切りと色付きの出力は、そのバイト列を保存します。すべての式・オプションの組合せを検証したものではありません。実行ファイルにコード署名はありません。
