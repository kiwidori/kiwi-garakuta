# きういJSONパス

JSONの各項目をパスと値の一覧に変換し、一覧をJSONへ戻せます。[gron v0.7.1](https://github.com/tomnomnom/gron/releases/tag/v0.7.1)の非公式GUIです。

[使い方とダウンロード](https://kiwi-garakuta.pages.dev/tools/kiwi-json-paths/)

ZIPを展開し、KiwiJsonPaths.exeを起動してください。Windows 11 x64向けです。

JSONを入力欄へ貼り付けるか、ファイル1つまたはHTTP/HTTPSのURLを指定します。「JSONをパス一覧へ」で項目を確認し、「結果を入力へ」で一覧を編集して「パス一覧をJSONへ戻す」で復元できます。元ファイルは書き換えません。結果の保存先は自分で選びます。

JSONL入力、パスと値のJSONストリーム表現、並べ替えの省略、ANSI色付き出力にも対応します。「原文を保存」は出力をそのまま、「色なしで保存」はANSI制御文字を除いたテキストを保存します。画面では色を除いて表示します。

「文字列・数値などを抽出」はパス一覧からトークンを取り出す機能です。引用符付きのキーや配列の添字も含まれる場合があります。通常画面では空行を除去し、一覧を検証してから抽出します。

処理は300秒、入力テキストとURL応答は2 MiB、通常の入力ファイルは20 MiB、抽出用ファイルは2 MiB、出力は16 MiBまでです。JSONL・復元は元ツールの1行1 MiB、抽出は1行64 KiB未満の制限があります。全オプションの組合せを保証するものではありません。実行ファイルは未署名です。

URLを指定した場合だけネットワークへ接続します。URLの接続・読み取り待ちは20秒までです。通常画面ではHTTPエラーを表示し、別ホストへの転送時に認証情報を引き継ぎません。TLS証明書の検証は既定で有効です。

詳細機能は同梱CLIを直接呼び出します。元ツールの挙動が適用され、--valuesはファイルやURLではなく標準入力を読みます。空行や長い行による元ツールの不具合を避けるため、値の抽出には通常画面を使ってください。URLの応答状態の確認も通常画面を推奨します。パス一覧はJavaScriptに似た表記ですが、このアプリではスクリプトとして実行しません。
